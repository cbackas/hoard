# Out of scope: anime, shared servers, automated tests

Deliberate no-s, so nobody "fixes" them by accident:

- **No anime.** SIMKL's anime list is dropped entirely; only Movies and Shows are shown.
- **Owned servers only.** Servers shared by friends don't count toward what's Collected; adding them means fetching from several possibly-unreachable servers.
- **No automated tests.** This is a small personal tool; a TypeScript typecheck is the only automated check.
